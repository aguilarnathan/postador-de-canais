Política de Privacidade

Última atualização: 7 de outubro de 2026

O Postador de Canais é uma ferramenta interna de Nathan Luis, usada apenas para gerenciar os seus próprios canais do YouTube. Esta política explica quais dados a ferramenta acessa e o que faz com eles.

Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os Termos de Serviço do YouTube. Os dados acessados pelo Google também seguem a Política de Privacidade do Google (http://www.google.com/policies/privacy).

Quais dados acessamos

  • Informações básicas do canal autorizado (nome e identificador do canal), para saber em qual canal o vídeo será enviado.
  • Os vídeos, títulos, descrições e comentários que o próprio dono envia pela ferramenta.
  • Estatísticas dos próprios vídeos do canal (visualizações, tempo assistido, retenção).

Não acessamos dados de espectadores, mensagens, canais de terceiros nem dados pessoais de outras pessoas.

Como usamos os dados

Os dados são usados somente para enviar e agendar vídeos, publicar o comentário inicial e acompanhar o desempenho dos próprios canais. Não vendemos, não compartilhamos e não transferimos dados para terceiros, e não usamos os dados para publicidade.

Armazenamento

O token de acesso do Google e os relatórios de estatísticas ficam guardados apenas no computador pessoal do dono dos canais. Nada é enviado a servidores próprios ou de terceiros. Não usamos cookies.

Exclusão e revogação

O acesso pode ser revogado a qualquer momento na página de permissões da conta Google: https://security.google.com/settings/security/permissions. Quando o acesso é revogado, ou mediante pedido pelo e-mail abaixo, os tokens e dados armazenados são apagados em até 7 dias. Dados obtidos da API que não forem atualizados são apagados em até 30 dias.

Privacy Policy (English)

Last updated: October 7, 2026

Channel Post Scheduler is an internal tool owned by Nathan Luis and used only to manage his own YouTube channels.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Data accessed through Google is also subject to the Google Privacy Policy.

Data we access

  • Basic information about the authorized channel (channel name and ID), to choose the destination of each upload.
  • Videos, titles, descriptions and comments that the owner submits through the tool.
  • Statistics of the channel's own videos (views, watch time, retention).

We do not access viewer data, messages, third-party channels or anyone else's personal data.

How we use data

Data is used only to upload and schedule videos, post the first comment and track the performance of the owner's own channels. We do not sell, share or transfer data to third parties, and we do not use it for advertising.

Storage

The Google access token and statistics reports are stored only on the channel owner's personal computer. Nothing is sent to our own or third-party servers. We do not use cookies.

Deletion and revocation

Access can be revoked at any time at https://security.google.com/settings/security/permissions. Once access is revoked, or upon request to the e-mail below, stored tokens and data are deleted within 7 days. API data that is not refreshed is deleted within 30 days.
